# Archives de répétition

[Tous les guides](../README.md)

Ces supports conservent le travail initial. **Pour une nouvelle sandbox, commencer par le [guide de démarrage actuel](../DEMARRER.md).**

- [Ancienne fiche ventes](guide-ventes-repetition.pdf) : support de la première répétition, avec ses noms de projets et ses liens de cluster. Les exemples restent utiles, mais ces adresses ne configurent pas un nouvel environnement.

Pour présenter aujourd’hui, utiliser la [fiche globale actuelle](../guide-presentation-openshift-ai-3.5.pdf). Les liens de la nouvelle installation sont produits localement dans `.state/<projet>/liens.json`.
